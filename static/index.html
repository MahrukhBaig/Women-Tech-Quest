    For competition evaluation, the scored level1.csv and level2.csv are generated via the deterministic CLI engine.

    PowerShell (Windows)
    & .venv\Scripts\python -m billdecoder.cli --bills-dir test\bills --level1-template test\csv\level1.csv --level2-template test\csv\level2.csv --output-dir output
    Bash (macOS / Linux)
    python -m billdecoder.cli --bills-dir test/bills --level1-template test/csv/level1.csv --level2-template test/csv/level2.csv --output-dir output

    Output files are generated into output/level1.csv and output/level2.csv strictly preserving template IDs and ordering.
